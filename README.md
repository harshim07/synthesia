# synthesia
A Full Stack Music Player Web Application developed using the MERN Stack during a Full Stack Web Development Internship at Web Stack Academy.
🚀 Features
User Registration & Login (JWT Authentication)
Browse and Play Songs
Upload and Manage Music
Create & Manage Playlists
Secure Password Reset (Mailtrap)
Avatar Upload (ImageKit)
Responsive UI with Smooth Audio Controls
🛠️ Tech Stack
⚛️ React (Frontend)
🟢 Node.js & 🚏 Express.js (Backend)
🍃 MongoDB (Database)
🔐 JWT Authentication
🏗️ Architecture
Client–Server Architecture using REST APIs with JSON communication between frontend and backend.
🎯 Outcome
Gained hands-on experience in full stack development, frontend-backend integration, authentication, and real-world MERN workflow.
